# A widget name without intent

**Skill:** design-system
**Route:** discovery
**Design:** fixtures/mini-ds/DESIGN.md
**Request:**

> Add a dropdown in the build page header, to the right of the Rebuild button.
> (Web Components binding, plain HTML.)

**Expected:**

- Recognise that “dropdown” does not establish intent. A command-menu interpretation makes DropdownMenu a reasonable provisional choice; a form-value interpretation leads to a picker. Ask whether the user needs commands/navigation or a saved value before implementation. Accept another provisional choice with a valid explicit assumption. Do not demand a printed list of every alternative.

- Discovery leaves project files unchanged.
